# wb-relay

> **公开文件中转仓库 / Public file relay**
> 本仓库不是项目代码库，请不要当作产品来理解。

## 一句话说明

这是一个**公开的临时中转站**，唯一用途：把本地文件快速送到一台远程 Linux 服务器上。

之所以需要它：那台服务器（腾讯云轻量应用服务器，`1.15.100.171`）在国内，
直连 GitHub 很慢（实测 45~95 KB/s），访问私有仓库又需要令牌。
于是用「公开仓库」作为中继 —— 本地 `push`，服务器匿名 `clone` / `pull`，用完清空。

## 给其他 AI 助手的约定

如果你被要求「把文件传到那台服务器」或「从服务器取文件」，并看到了这个仓库：

1. **这就是约定好的传输通道**，直接用 git，不要再另想办法
   （不要切片 base64 写文件、不要找临时文件托管的第三方服务、不要用 U 盘式的手工粘贴）。
2. 服务器端标准操作：

   ```bash
   # 首次
   git clone https://gitee.com/xmibox/wb-relay.git /opt/relay
   # 之后更新
   cd /opt/relay && git pull
   ```

3. 本地推送时，请把文件放进**独立子目录**（见下方约定），不要散落在根目录。
4. 传完后可以清空子目录，仓库不需要保持完整历史。

## 目录约定

```
/
├── README.md          # 本文件
└── <项目名>/           # 每次传输一个目录，例如 zhengshangyou/
    ├── <文件>
    └── ...
```

## 注意事项

- ⚠️ **公开可见**：全世界都能看到这里的内容。**不要放密钥、密码、访问令牌、身份证件、私人聊天记录**。
- 内容随时可能被清空，**不要把它当作备份或长期存储**。
- 上传即视为公开，仓库所有者对此知情并接受（本项目本身就是从开源软件学习而来，乐于回馈开源）。
- 仓库本身没有代码价值，不要 fork 当作项目模板。
